## AI Project: Mini RAG

Bucky built a production-style Mini RAG system in TypeScript.

The system includes:

- document chunking
- configurable chunk size
- chunk overlap
- sentence-boundary handling
- chunk metadata
- embedding generation
- semantic similarity retrieval
- Top-K retrieval
- similarity thresholds
- metadata filtering
- context construction
- LLM answer generation
- automated retrieval evaluation
- answer evaluation

The project evaluates retrieval quality using Precision@K and Recall@K.

It also evaluates generated answers using faithfulness and answer relevance checks.

The project is designed to help identify whether failures come from retrieval, missing context, irrelevant context, or answer generation.
